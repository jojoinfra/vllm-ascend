# Replay stage 1

Work from the pinned A5 image and the original 48-shard model directory. The model plugin, launch scripts and frozen validator are independent of an InferRSI installation. The task's local evidence bundle contains the plan and the resulting records.

1. Copy `patch/`, `validator/` and `plan/` into a private working directory. Run `python3 patch/infra/fetch-reference.py plan/input-freeze.json reference/hf` there, or reuse files verified by the same manifest. Set `WORK` to that absolute directory, `MODEL_PATH` to the original weights and `CONTAINER` to a new container name.
2. Acquire an exclusive eight-card reservation and service port. Verify external container ownership and device availability, then set `LEASED_DEVICES` to the returned physical IDs. Run `bash patch/infra/container.sh` on the reserved host. The snapshot's device order is 0 through 7. All weights are mounted read-only.
3. In the new container run `bash /stage1/patch/infra/in-env.sh python -m pip install --no-build-isolation --no-deps -e /stage1/patch`. Set `HCCL_PROBE_RESULTS` to a new directory. Run `bash /stage1/patch/infra/in-env.sh torchrun --standalone --nproc-per-node=8 /stage1/patch/infra/hccl_probe.py`. Check all eight rank receipts and the reduced value.
4. From the evidence bundle copy the paired HF CPU Engram fixture and JSON metadata into the runtime results directory. Run the eight-worker Engram comparison described by `python -m dsv41_stage1.verify_engram --help`, passing that fixture, the frozen HF inference directory and a new per-rank output path.
5. Set `PORT` to the reserved port and `RUN_NAME` to a new attempt name in the container. Run `bash /stage1/patch/infra/replay.sh`. It launches vLLM, checks the service and captures its generation and numerical records. On exit it terminates its child server. Preserve logs and run manifests for unsuccessful attempts as well.
6. Compare the numerical trace against the independent reference with `validator/compare_traces.py`. Retrieve results, stop the task's own container and release the reservation. The rank load ledgers, service responses and scope of numerical agreement accompany the verdict.
